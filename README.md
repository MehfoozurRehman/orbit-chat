# Messenger: Real-Time Web Chat & Direct Messaging Client

A responsive real-time web messaging client, conversation thread viewer, and direct communication interface built with React 18, Vite 4, TypeScript, and SCSS.

## Overview

`messenger` delivers a smooth chat experience: conversation threads, contact indexing, Feather Icons, SEO meta management via `react-helmet`, and optimized production asset compression.

## Tech Stack

- **Frontend Core**: React 18, [Vite](https://vitejs.dev/) (v4), React Router DOM v6, TypeScript
- **UI & Icons**: Feather Icons (`react-feather`), SCSS / SASS
- **Asset Optimization**: `vite-plugin-chunk-split`, `vite-plugin-compression`, `vite-plugin-imagemin`

## Prerequisites

- Node.js (v18 or higher recommended)
- Package manager (`npm` or `pnpm`)

## Getting Started

1. **Navigate to the client and install dependencies**:
   ```bash
   cd client
   npm install
   ```

2. **Run the Development Server**:
   ```bash
   npm run dev
   ```

3. **Access the Chat Client**:
   Open `http://localhost:5173` in your web browser.

## Available Scripts

- `npm run dev` - Starts the Vite dev server with instant HMR.
- `npm run build` - Compiles and bundles for production.
- `npm run preview` - Previews production build locally.
- `npm run formate` - Formats the codebase using Prettier.
